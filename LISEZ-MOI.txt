INSTALLER L'ADMINISTRATION (Android, PC) - 3 fichiers a remplacer / ajouter dans GitHub

  html/admin.html                  remplace l'ancien (ajoute le manifeste + install.js)
  manifest-admin.webmanifest       NOUVEAU, a la racine du depot
  js/install.js                    remplace l'ancien (textes "Maison Admin" sur /admin)

vercel.json, dans "headers", ajouter :
  { "source": "/manifest-admin.webmanifest", "headers": [
      { "key": "Content-Type", "value": "application/manifest+json" } ] }

INDISPENSABLE AVANT TOUT (sinon rien ne s'installe) :
  Vercel > projet location_maison > Settings > Deployment Protection
  > "Vercel Authentication" : DESACTIVER (ou ajouter un nom de domaine personnalise).
  Tant qu'elle est active, le manifeste et le service worker sont bloques pour tous
  les visiteurs : ni Android ni PC ne proposent l'installation, et vos clients ne
  peuvent meme pas ouvrir le site sans compte Vercel.
