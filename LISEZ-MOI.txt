WHATSAPP PAR QR CODE (Green API) + CORRECTIF E-MAIL

FICHIERS A REMPLACER DANS GITHUB (mêmes chemins) :
  api/_lib.js   api/console.js   js/admin.js   css/admin.css   css/dashboard.css
(aucune nouvelle fonction Vercel)

VERCEL > projet location_maison > Settings > Environment Variables (type Sensitive), puis Redeploy :
  GREEN_API_ID    = valeur "idInstance" de la console Green API
  GREEN_API_TOKEN = valeur "apiTokenInstance"
  GREEN_API_URL   = valeur "apiUrl" (ex. https://7107.api.greenapi.com)   sans / final

Ensuite : dashboard super admin > Système > WhatsApp > scanner le QR (WhatsApp > Appareils
connectés) > "Envoyer le test".

SECURITE : ne partagez jamais apiTokenInstance (captures d'écran comprises). S'il a été montré,
régénérez-le dans la console Green API (icône flèche circulaire à côté du jeton) AVANT de le mettre
dans Vercel.
