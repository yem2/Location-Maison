MODULE WHATSAPP (Green API) + NOM « Gestion immobilière »
Conçu pour la version EN LIGNE actuelle (admin.js avec Archives, Contrats & reçus, api/payments).
Rien n'écrase vos fichiers existants : 2 fichiers nouveaux + 1 manifeste + 4 petites modifications.

A. AJOUTER (nouveaux fichiers, mêmes chemins dans GitHub)
   api/whatsapp.js        (12e fonction Vercel sur 12 autorisées : plus de place pour une autre ensuite)
   js/admin-whatsapp.js
B. REMPLACER
   manifest.webmanifest   (nom de l'application : Gestion immobilière)

C. MODIFIER 4 LIGNES (GitHub > fichier > icône crayon > Ctrl+F > Commit)
 1) html/admin.html  (ou admin.html selon votre dépôt) : ajouter cette ligne juste AVANT la ligne admin.js
      <script src="/js/admin-whatsapp.js" defer></script>
 2) js/admin.js : chercher
      "Location et vente immobilière", h("small", {}, "Administration")
    remplacer par
      "Gestion immobilière", h("small", {}, "Administration")
 3) js/admin.js : chercher
      ["suggestions", "Suggestions", "suggestions"]] },
    remplacer par
      ["suggestions", "Suggestions", "suggestions"], ["whatsapp", "WhatsApp", null, 1]] },
 4) js/admin.js : chercher
      : tab === "chat" ? chatView() : tab === "suggestions" ? suggestionsView()
    remplacer par
      : tab === "chat" ? chatView() : tab === "whatsapp" && sup ? window.AdminWhatsApp.view(ctx) : tab === "suggestions" ? suggestionsView()
 => l'onglet « WhatsApp » apparaît dans Messagerie (super administrateur uniquement).

D. VERCEL > Settings > Environment Variables (Sensitive) puis Redeploy
   GREEN_API_ID, GREEN_API_TOKEN, GREEN_API_URL  (valeurs idInstance, apiTokenInstance, apiUrl)

E. FAIRE PARTIR LES NOTIFICATIONS PAR GREEN API (api/_lib.js)
   Dans waSend(to, text), ajouter en première ligne :
      { const g = await import("./whatsapp.js"); if (g.greenOn()) return g.sendGreen(to, text); }
   puis, dans maybeWhatsApp et au 2e endroit où WA_ACCESS_TOKEN est testé, remplacer
      process.env.WA_ACCESS_TOKEN
   par
      (process.env.WA_ACCESS_TOKEN || process.env.GREEN_API_ID)
   (si les lignes de votre _lib.js sont différentes, envoyez-moi le fichier)

SECURITE : le jeton apiTokenInstance a été visible sur une capture d'écran. Régénérez-le dans la
console Green API (icône flèche circulaire à côté du jeton) avant de le coller dans Vercel.
